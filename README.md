# Wafaa & Mustafa Engagement Website

موقع خطوبة تفاعلي يعمل على الموبايل والكمبيوتر، بدون أي أدوات بناء أو اشتراكات.

## تجربة الموقع
افتح ملف `index.html` في المتصفح. يلزم اتصال بالإنترنت لتحميل الخطوط من Google Fonts.

## إضافة الصور
الصور الأساسية موجودة في نفس المجلد مع `index.html` باسم `1.jpg` و`2.jpg`. يعرض الموقع الصورتين مرة واحدة جنبًا إلى جنب، ويستخدمهما أيضًا كنقشة خلفية خافتة، ويمكن تعديلها من `index.html`.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub باسم `wafaa-mustafa`.
2. ارفع `index.html` و`1.jpg` و`2.jpg` إلى جذر المستودع في نفس المستوى.
3. من Settings → Pages → Build and deployment اختر Deploy from a branch ثم `main` و `/ (root)` واضغط Save.
4. بعد اكتمال النشر سيكون العنوان عادةً `https://YOUR-USERNAME.github.io/wafaa-mustafa/`.

## قبل مشاركة الدعوة
- استبدل الصور الافتراضية بصور أصحاب المناسبة.
- موعد الحفل يوم الأحد 8 نوفمبر 2026 الساعة 8:00 مساءً.
- تأكد من العنوان التفصيلي للقاعة. يمكن لاحقًا إضافة زر خرائط برابط موقع موثوق.
- الموقع عام، لذلك أي شخص معه الرابط يستطيع رؤية الصور.
